## What this means for Website Ventures

### €349 is not absurd — but it is low-end positioning

There is at least one active Dutch provider publicly using €349 as a starting point, so the number is not disconnected from the market. But many visible offers cluster materially higher, often €499–€995+ depending on scope.

Therefore the Website Ventures hypothesis should be:

**€349 can be a deliberate founding / acquisition price only when the product is bounded and the production system keeps active labour low.**

It should not become an emotional ceiling such as “local tradespeople will never pay more.” The current sample gives no basis for that conclusion.

## Recommended price experiment structure

Not yet a locked public offer:

### Phase 1 — founding evidence
- Test €349 on a tightly bounded reusable product.
- Do not include unlimited copywriting, redesigns, custom features, logo work or indefinite support.
- Measure *all active minutes*: sales/admin + intake + build + revisions + domain/launch + handoff.

### Phase 2 — after a few real deliveries
Compare:
- close rate;
- objection rate;
- active minutes;
- revision burden;
- contribution margin;
- referral rate.

Then test whether the next clean price should be €499, €599, €699 or another number rather than automatically keeping €349.

### Phase 3 — segment
If the system proves itself, preserve a simple base product and price additions separately for work that breaks repeatability.

Examples that should usually trigger a scope/price decision rather than silently enter the base package:
- custom functionality;
- substantial copywriting;
- multi-language;
- booking/e-commerce;
- large migration;
- large photo/video work;
- logo/rebrand;
- many custom pages;
- repeated revision cycles;
- complex integrations.

## Critical economics rule

Do not judge €349 by “build time” alone.

The real denominator is:

**sales/admin + qualification + intake + production + customer waiting management + revisions + QA + domain/hosting + launch + handoff + support burden.**

Use `website-ventures-unit-economics.html` with the real `Fulfilment Run` numbers from customers 1–10.

## Current conclusion

- **€349 = plausible founding hypothesis, not proven optimum.**
- Current public market examples make **€499–€799** credible territory for a polished bounded small-business product once proof exists.
- **€995+** is common enough in the sample that Website Ventures should not assume a hard ceiling below that for stronger/custom packages.
- The production-line advantage should improve margin and speed, not automatically force the customer price down to the minimum possible number.
