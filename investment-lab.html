    03 / KOPPELINGEN VERKENNEN

    De API bestaat al.

    De technische mogelijkheden verschillen per platform. Onderzocht op 12 november 2026; jouw accounttoegang is nog niet gecontroleerd.

    Trading 212DEMO + LIVE API

    Posities, rekeningoverzicht en orders. API in bèta voor Invest en Stocks ISA; bedragen in de hoofdvaluta. Voor Nederland is Invest de relevante rekeningvorm.

    Officiële API-documentatie ↗
    Interactive BrokersUITGEBREIDE API

    Web API en TWS API, met een paperomgeving. De particuliere Web API gebruikt volgens de startgids een lokale Client Portal Gateway; dit vraagt extra infrastructuur.

    Officiële startgids ↗
    SaxoOPENAPI + SIM

    Een aparte simulatieomgeving en liveomgeving. Livegebruik vereist toegang en tests; sommige rapportage- en marktdatafuncties ontbreken in SIM.

    Officiële omgevingen ↗
    AlpacaPAPER API

    Een Paper Only-account is volgens de documentatie wereldwijd beschikbaar. Dat bevestigt geen Nederlandse live-accounttoegang; die moet apart worden gecontroleerd. Paperdata gebruikt IEX.

    Officiële paperdocumentatie ↗

    Voorbereid voor een volgende stap: alleen rekening en posities uitlezen uit Trading 212 Demo of Alpaca Paper. De proef heeft geen verbinding en vraagt geen API-sleutels.
