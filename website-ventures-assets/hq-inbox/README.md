# HQ shared image inbox

Upload website images and Gamenfy badges here through the GitHub upload link in Project HQ. Use unique names; preserve originals. Do not put credentials or private customer material here: this folder follows repository and deployment visibility.

Files on main are stored in the repository, not automatically selected or integrated into a website. Review and promotion remain separate. Builders: inspect this folder when Joey reports a new upload and retain the source filename/provenance when integrating it.

The HQ gallery reads GitHub's public Contents API on request. If the repository becomes private or GitHub limits requests, it reports an unverified status and offers the authenticated GitHub folder link. It never mistakes browser-local storage for a completed repository upload.
