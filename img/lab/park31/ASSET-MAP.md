# Park 3.1 artwork drop format

Park 3.1 has **11 Daily Mission companions**, each with **10 level images**. Every image must be a WebP named `l01.webp` through `l10.webp`.

| Live data key | UI name | Asset directory |
| --- | --- | --- |
| `walking` | Steps | `steps/` |
| `nutrition` | Nutrition | `nutrition/` |
| `teeth` | Brush Teeth | `teeth/` |
| `household` | Household | `household/` |
| `gratitude` | Gratitude | `gratitude/` |
| `good_deed` | Good Deed | `good-deed/` |
| `screen_time` | Screen Time | `screen-time/` |
| `cold_shower` | Cold Shower | `cold-shower/` |
| `weed_control` | Gardening | `no-weed/` |
| `no_porn` | Discipline | `discipline/` |
| `sleep` | Sleep | `sleep/` |

All directories live beneath `img/lab/park31/`. Example: Level 4 Cold Shower belongs at `img/lab/park31/cold-shower/l04.webp`.

All eleven companion sets are complete. Gratitude and Nutrition use technically cleaned Gouden Paard artwork. Brush Teeth was re-cleaned to remove checkerboard and effect-edge remnants without changing the characters. Cold Shower Levels 1–10 now use true transparent cutouts without the embedded amusement-park scenery. Good Deed, Steps and Sleep are also true transparent cutouts: their approved characters, platforms, clouds and level effects remain while the fixed navy rectangles are gone. Household Level 1 is the deliberately stronger, mess-heavy starter form; Levels 2–10 keep the cleaned Gouden Paard progression.
