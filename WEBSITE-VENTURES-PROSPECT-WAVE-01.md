# Website Ventures — Prospect Wave 01

Research date: 2026-09-07
Prepared by: ChatGPT (OpenAI)
Status: **research only — nobody contacted**

## Purpose

Create the first real outbound shortlist for the Premium Plumbing / Installations wedge instead of endlessly refining the product without sales evidence.

This is a **public-web research shortlist**, not a claim that every company wants or needs a new website. Scores are provisional until the site is checked manually on iPhone and the actual decision-maker is verified.

## Scoring model

Seven points maximum:
1. Existing real business.
2. Strong real-world capability/reputation visible.
3. Website/presentation gap appears meaningful.
4. A lead/customer is commercially valuable.
5. Need fits a standardized marketing website.
6. Decision-maker likely reachable.
7. Truthful assets/proof likely available.

- 6–7: A-list — contact first.
- 4–5: B-list — second wave / manual check first.
- 0–3: skip for now.

## Before any contact

For each A-list prospect:
- open current site on iPhone/mobile;
- write one factual sentence about the visible gap;
- verify the company is still active and the public contact route is current;
- do **not** generate a fully personalized website first;
- lead with the already-built Premium Plumbing flagship;
- only make a personalized 5–15 minute mock if the prospect shows interest or if one specific visual substitution would dramatically improve the demo.
